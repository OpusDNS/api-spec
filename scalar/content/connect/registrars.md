# What OpusDNS can do per registrar

Until you transfer a domain to OpusDNS, it stays at your current registrar. OpusDNS syncs it from there and makes some changes there for you. This page shows which ones, for each registrar.

✅ OpusDNS does it for you · ↗️ you do it at your registrar · ➖ the TLD doesn't have it

## At every registrar

- ✅ See the nameservers
- ✅ See the contacts
- ↗️ Change the registrant
- ↗️ Change the other contacts
- ↗️ Remove a contact role
- ↗️ See WHOIS privacy
- ↗️ Turn WHOIS privacy on or off

## Depends on the registrar

| Registrar | See the transfer lock | Set or remove the transfer lock | Change the nameservers |
| --- | :---: | :---: | :---: |
| [CentralNic Reseller](#centralnic-reseller) | ✅ | ✅ | ✅ |
| [eNom](#enom) | ✅ | ✅ | ✅ |
| [InterNetX](#internetx) | ✅ | ✅ | ✅ |
| [Moniker](#moniker) | ✅ | ✅ | ↗️ |
| [NIC Direct](#nic-direct) | ↗️ | ↗️ | ↗️ |
| [NICManager](#nicmanager) | ✅ | ✅ | ↗️ |
| [Openprovider](#openprovider) | ✅ | ✅ | ✅ |
| [OpenSRS](#opensrs) | ✅ | ✅ | ✅ |
| [PartnerGate](#partnergate) | ↗️ | ✅ | ✅ |
| [Realtime Register](#realtime-register) | ↗️ | ↗️ | ✅ |

## CentralNic Reseller

To transfer a domain from CentralNic Reseller, see [Transfer from CentralNic Reseller](/transfers/registrars/centralnic).

**Transfer lock**

| Action | Note |
| --- | --- |
| ✅ See the transfer lock | OpusDNS reads the transfer lock at CentralNic Reseller. |
| ✅ Set or remove the transfer lock | OpusDNS sets and removes the lock through the CentralNic Reseller API. |

TLDs where this differs:

| TLDs | What differs |
| --- | --- |
| [.at](/tld-knowledge-base/cctlds/at), [.ch](/tld-knowledge-base/cctlds/ch), [.co.za](/tld-knowledge-base/cctlds/co.za), [.cz](/tld-knowledge-base/cctlds/cz), [.de](/tld-knowledge-base/cctlds/de), [.dk](/tld-knowledge-base/cctlds/dk), [.eu](/tld-knowledge-base/cctlds/eu), [.gr](/tld-knowledge-base/cctlds/gr), .is, [.it](/tld-knowledge-base/cctlds/it), [.li](/tld-knowledge-base/cctlds/li), [.lt](/tld-knowledge-base/cctlds/lt), [.lu](/tld-knowledge-base/cctlds/lu), [.mx](/tld-knowledge-base/cctlds/mx), [.net.za](/tld-knowledge-base/cctlds/net.za), [.nl](/tld-knowledge-base/cctlds/nl), [.no](/tld-knowledge-base/cctlds/no), [.nu](/tld-knowledge-base/cctlds/nu), [.org.za](/tld-knowledge-base/cctlds/org.za), [.pl](/tld-knowledge-base/cctlds/pl), [.pt](/tld-knowledge-base/cctlds/pt), [.ro](/tld-knowledge-base/cctlds/ro), [.se](/tld-knowledge-base/cctlds/se), [.si](/tld-knowledge-base/cctlds/si), [.web.za](/tld-knowledge-base/cctlds/web.za) | ➖ No transfer lock |

**Nameservers**

| Action | Note |
| --- | --- |
| ✅ See the nameservers | OpusDNS reads the nameservers in each sync. |
| ✅ Change the nameservers | OpusDNS changes the nameservers through the CentralNic Reseller API. |

**Contacts**

| Action | Note |
| --- | --- |
| ✅ See the contacts | OpusDNS reads the contacts in each sync. |
| ↗️ Change the registrant | OpusDNS can't change the registrant of a connected domain. Change it at CentralNic Reseller. |
| ↗️ Change the other contacts | OpusDNS can't change the other contacts of a connected domain. Change them at CentralNic Reseller. |
| ↗️ Remove a contact role | OpusDNS can't remove a contact from a connected domain. Remove it at CentralNic Reseller. Not every TLD allows it. See the [TLD Knowledge Base](/tld-knowledge-base). |

**WHOIS privacy**

| Action | Note |
| --- | --- |
| ↗️ See WHOIS privacy | OpusDNS has no access to WHOIS privacy at CentralNic Reseller. Check it at CentralNic Reseller. |
| ↗️ Turn WHOIS privacy on or off | OpusDNS has no access to WHOIS privacy at CentralNic Reseller. Change it at CentralNic Reseller. |
