# No auth code, with approval

These TLDs need no auth code. OpusDNS requests the transfer. Your current registrar can then approve or deny the transfer. The registry has no transfer lock.

## Steps

1. OpusDNS requests the transfer at the registry.
2. Your current registrar approves or denies the transfer. Some registrars ask the domain's holder by email.

Each TLD's page shows which of these steps OpusDNS takes at your registrar.

## TLDs

[.co.za](/transfers/patterns/no-auth-code/co.za), [.lu](/transfers/patterns/no-auth-code/lu), [.net.za](/transfers/patterns/no-auth-code/net.za), [.org.za](/transfers/patterns/no-auth-code/org.za), [.web.za](/transfers/patterns/no-auth-code/web.za).

## Registries

These registries handle transfers this way:

- [ZARC](https://zarc.web.za): [.co.za](/transfers/patterns/no-auth-code/co.za), [.net.za](/transfers/patterns/no-auth-code/net.za), [.org.za](/transfers/patterns/no-auth-code/org.za), [.web.za](/transfers/patterns/no-auth-code/web.za)
- [Fondation RESTENA (DNS-LU)](https://www.dns.lu): [.lu](/transfers/patterns/no-auth-code/lu)
