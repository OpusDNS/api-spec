# Transferring a .nu domain

`.nu` follows the [Auth code set by the registry](/transfers/patterns/registry-auth-code) pattern. Its registry has no transfer lock. A transfer doesn't extend the registration. The registry completes a transfer at once.

## Steps

1. Get the auth code from your current registrar or the registry.
2. OpusDNS requests the transfer at the registry with the auth code.
3. The registry completes the transfer without an approval.

## At your registrar
