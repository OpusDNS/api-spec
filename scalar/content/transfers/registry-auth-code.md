# Auth code from the registry

The registry issues the auth code, not your current registrar. OpusDNS requests the transfer with it. The registry completes the transfer at once, without an approval.

## Steps

1. Remove the transfer lock at your current registrar, where the TLD has one.
2. Get the auth code. How you get it depends on the TLD. The TLD's page in the [TLD Knowledge Base](/tld-knowledge-base) explains it.
3. OpusDNS requests the transfer at the registry with the auth code.
4. The registry completes the transfer at once.

## TLDs

[.be](/tld-knowledge-base/cctlds/be), [.cz](/tld-knowledge-base/cctlds/cz), [.dk](/tld-knowledge-base/cctlds/dk), [.eu](/tld-knowledge-base/cctlds/eu), [.gr](/tld-knowledge-base/cctlds/gr), [.lt](/tld-knowledge-base/cctlds/lt), [.nl](/tld-knowledge-base/cctlds/nl), [.nu](/tld-knowledge-base/cctlds/nu), [.ro](/tld-knowledge-base/cctlds/ro), [.se](/tld-knowledge-base/cctlds/se).

A transfer lock only at [.be](/tld-knowledge-base/cctlds/be).
